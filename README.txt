GRADE 4 MATH INSTRUCTIONAL PLANNING RESOURCE

Open index.html locally, or upload the entire contents of this folder to a static web host after obtaining authorization for public redistribution of third-party materials and local assessment results.

Original TCMPC specificity images, original lead4ward question images, testing frequencies, and local 2025/2026 response distributions are included. Correct local choices are highlighted in green. Source response labels may be A/B/C/D or F/G/H/J; those are preserved exactly as in the local report. Numeric-entry questions may use scoring categories rather than literal answer choices.

No student names are included. The source screenshots themselves must be reviewed for branding before public hosting.
